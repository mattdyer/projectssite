# Project Ideas

Browser-only games and interactive apps. Each completed project gets its own subfolder under `docs/` and a link in `docs/index.htm`.

## Games

- [x] **Snake** — Classic snake game on a canvas grid, with increasing speed as you eat.
- [x] **Breakout / Arkanoid** — Bouncing ball, paddle, and rows of colored bricks to destroy.
- [x] **Space Invaders** — Rows of aliens moving side-to-side, player shoots upward.
- [x] **Pong** — Two-player or AI-vs-player paddle-ball game.
- [x] **Minesweeper** — Click to reveal cells, avoid mines, number hints on neighbors.
- [x] **Tetris** — Falling tetrominoes, rotate/move, clear complete rows.
- [x] **2048** — Slide-number puzzle that merges matching tiles.
- [x] **Flappy Bird** — Tap/click to fly through gaps between pipes.
- [x] **Memory Match** — Grid of cards, flip two at a time to find matching pairs.
- [x] **Reaction Time** — Measure how fast the user can click when color changes.
- [x] **Whack-a-Mole** — Random holes pop up, click them before they hide.
- [x] **Doodle Jump** — Procedural platforms, jump higher and higher without falling.
- [x] **Simon Says** — Sequence of colors/sounds the user must repeat back.
- [x] **Tic-Tac-Toe** — Classic X-O on a 3x3 grid, vs AI or two-player.
- [x] **Connect Four** — Drop discs into columns, get four in a row, with AI opponent.
- [x] **Word Scramble** — Scramble a word, user unscrambles it against the clock.
- [x] **Hangman** — Guess letters to reveal a hidden word.
- [ ] **Battleship** — Place ships on a grid, guess opponent's ship locations.
- [ ] **Gravity Soccer** — Ball with physics, kick it into the goal past a goalkeeper.
- [ ] **Particle Physics Toy** — Simulate gravity between objects, users place masses.
- [x] **Conway's Game of Life** — Cellular automaton on a grid; start with a pattern and watch it evolve.

## Art / Visual Tools

- [ ] **Pixel Art Editor** — Grid-based drawing tool with color palette, fill, and export.
- [ ] **Mandala Generator** — Symmetrical art tool where you draw one stroke and it mirrors.
- [ ] **Fractal Explorer** — Interactive Mandelbrot/Julia set zoom and pan.
- [ ] **Waveform Synth** — Draw a waveform shape and hear it as sound.
- [ ] **Generative Art — Flow Fields** — Particles flowing along a noise-based vector field.
- [ ] **Color Mixer** — Blend colors interactively using sliders or drag-to-mix.
- [ ] **Rotoscope** — Upload an image, trace over it with draggable lines/curves.
- [ ] **Maze Generator** — Auto-generate a maze, user can solve it by navigating.
- [ ] **Chaos Game** — Fractal points drawn by random vertex selection rules.
- [ ] **Spirograph** — Draw spirograph patterns by adjusting gear parameters.
- [ ] **Music Visualizer** — Canvas visualizes microphone input as bars, circles, or waves.
- [ ] **Kaleidoscope** — Mirror the mouse cursor in real time to create kaleidoscopic patterns.
- [ ] **Gravity Drawing** — Draw strokes that fall with simulated gravity.
- [ ] **Digital Clock with Particle Background** — Time display with animated particles.

## Utilities / Fun

- [ ] **Stopwatch / Timer** — Lap times, countdown timer with visual alarm.
- [ ] **Dice Roller** — Roll 1–N dice, show results, keep history.
- [ ] **Coin Flip** — Animated coin flip with heads/tails history.
- [ ] **Random Name Picker** — Paste names, randomly pick one.
- [ ] **Color Palette Generator** — Generate harmonious color palettes from a seed.
- [ ] **Typing Speed Test** — Type the displayed text as fast as possible, WPM + accuracy.
- [ ] **Number Guessing Game** — Computer picks a number, user guesses with high/low hints.
- [x] **Rock Paper Scissors** — Play vs computer, animated, track score.
- [ ] **Mad Libs Generator** — Prompt for words, assemble a silly story.
- [ ] **Joke of the Day** — Fetch a random joke from an API and display it.
- [ ] **Pomodoro Timer** — 25-min work / 5-min break cycle with visual progress.
- [ ] **Breathing Exercise** — Animated circle expands/contracts for guided breathing.
- [ ] **QR Code Generator** — Type text, render a QR code on canvas.
- [ ] **Password Generator** — Adjustable length, character types, copy to clipboard.
- [ ] **Unit Converter** — Length, weight, temperature, currency conversions.
- [ ] **Age Calculator** — Input birthdate, display age in years/months/days/seconds.
- [ ] **Countdown to Event** — Enter a date, see a live countdown.
